The Problem

Indian staffing agencies lose qualified candidates because manual resume screening takes days. Recruiters fail to follow up before candidates accept other offers. Agencies were drowning in PDF attachments without structured scoring.

What I Built

A full workflow tool with automated resume parsing, Kanban candidate stages, AI voice screening, and automated candidate messaging. Designed screens in Figma, built backend flows in Python and Flask, and structured persistence on Supabase (PostgreSQL).

Core Product Decisions

  • Model Switch: Replaced the Gemini backend with NVIDIA NIM running Llama 3.1 8B. This cut response latency and lowered per-parse compute costs significantly.
  • Freemium Pricing: Replaced a restrictive 15-day trial lockout with a permanent 5-tier freemium model. Tiers range from 250 free monthly parses up to an enterprise tier of INR 59,999 per month.

Real Production Fixes

  • Cache invalidation bug: Resolved a cache bug that displayed outdated subscription tier labels to active paying users.
  • Kanban sync revert: Fixed an asynchronous database sync issue where dragged candidate stages reverted after a browser refresh.
  • Bulk ingestion pipeline: Re-architected file ingestion to prevent server timeouts. The new pipeline processes roughly 1,000 resumes in 10 minutes.
